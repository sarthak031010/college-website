## **Project Overview**

The website is designed to represent the core information about the institute in a professional and visually appealing way.  
It includes:
- A **responsive navigation bar** with logo, address, sign-in button, and dropdown menus.  
- **Marquee announcements** for highlighting important news.  
- Dedicated sections for **courses**, **departments**, and **facilities**.  
- **About Us** section with an image overlay for institute introduction.  
- **Timeline section** describing the educational programs: B.Com, B.Tech, MBA, Pharmacy, and Polytechnic.  
- **Login and Sign-Up functionality** implemented via modals for better user experience.  
- **Footer** section with “Back to Top” button and hover effects.  

This project is designed for demonstration purposes and can be used as a **portfolio project** for front-end developers.

---

## **Features**

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices.  
- **Interactive Navbar**: Hover effects, dropdown menus, and clickable links.  
- **Marquee for Announcements**: Scrolls vertically or horizontally for important updates.  
- **About Section**: Image overlay with textual description for institute details.  
- **Courses & Departments**: Highlighted with boxes, colors, and descriptions.  
- **Timeline**: Educational programs timeline in vertical format.  
- **Login/Sign-Up Modals**: Pop-up forms for user registration and login.  
- **Footer**: Hover effect with border animation.

## **Technologies Used**

- **HTML5**: Structure of the website.  
- **CSS3**: Styling, responsive design, hover effects, flexbox layout, media queries.  
- **JavaScript**: Modal open/close interactions and optional dynamic behavior.  
- **Font Awesome**: Icons for navigation and address section.

## **Pages and Components**

1. **index.html**
   - Navbar with logo, address, sign-in button, account link.  
   - Marquee announcements.  
   - About section with image overlay and scrolling text.  
   - Courses and facilities section in colored boxes.  
   - Footer with back-to-top button.  

2. **login.html**
   - Login form with username and password input fields.  
   - Sign-up modal embedded within the login page.  

3. **signup.html / modal**
   - Pop-up modal with sign-up form.  
   - Fields: Email, Password, Repeat Password, Remember Me checkbox.  
   - Cancel and Submit buttons.  

4. **timeline.html**
   - Timeline of educational programs: B.Com → B.Tech → MBA → Pharmacy → Polytechnic.  
   - Responsive vertical layout with arrows and circles.  

5. **department.html**
   - Page to list all academic departments with descriptions and images.  

6. **branch.html**
   - Information on different engineering and management branches.
